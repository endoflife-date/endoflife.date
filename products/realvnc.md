> [RealVNC Connect](https://www.realvnc.com/en/connect/) (formerly VNC Connect) is a remote access
> application for Windows, macOS, Linux and Raspberry Pi. It is made of RealVNC Server, installed
> on the computers to control, and RealVNC Viewer.

RealVNC Connect 7 and 8 are supported in parallel. Version 8 merged RealVNC Server and Viewer into
a single application. Within each supported major version, only the current release receives
security updates and critical fixes. The previous two minor releases are only eligible for product
support.

RealVNC Server 7 and RealVNC Viewer 7 are now released with separate version numbers, and RealVNC
Viewer 7 has been renamed RealVNC Classic Viewer. The latest version shown for version 7 is the
highest of the two.

VNC 5.x reached end-of-life on 3 October 2022.
