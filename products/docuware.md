> [DocuWare](https://start.docuware.com/) is a document management and workflow automation
> platform, available as a cloud service or installed on-premises on Windows Server.

Each DocuWare version is supported for 3 years from its release date. New versions are usually
released twice a year, in spring and in fall. DocuWare Cloud is updated automatically, so this page
only applies to on-premises installations.

Since DocuWare 7, updates and hotfixes are rolled into the full setup package of each version, so
the latest setup of a version always includes all published fixes.

At the end of a version's lifecycle, technical support is limited to usage and configuration
questions, and the version no longer receives updates or hotfixes. Support for DocuWare 7.9 is
already limited to general troubleshooting and hotfix packs that have been published.
