> [OpenStack](https://www.openstack.org/) is an open source cloud computing platform for building and managing public and private cloud infrastructure.

OpenStack follows a six-month release cycle. Each release is maintained through a defined set of maintenance phases,
with support eventually ending when the release reaches End Of Life.

OpenStack publishes release schedules and maintenance information for each release series through the OpenStack release team.
